The [examples folder](https://github.com/vardius/peer-data/tree/master/examples) holds three small apps. The
chat and the call are modules with tests that run them over real peer connections in a browser, and the
code here wires them to the DOM. Serve them all from a clone of the repository:

```sh
npm ci
npm run examples
```
